## 📌 Overview

**SmartTour** is a **complete tourism management platform** that connects:

- 🏖️ **Tourists** – Book hotels, tours, and restaurants
- 🎓 **Students** – Find jobs, courses, and internships
- 🗺️ **Tour Guides** – Manage tours, bookings, and earnings

Built with **PHP**, **MySQL**, **HTML**, **CSS**, and **JavaScript** – designed to be a one-stop solution for Sri Lanka's tourism industry.

---

## ✨ Features

### 🏨 For Tourists
- 🔍 **Hotel Search** – Filter by location, price, and star rating
- 🗺️ **Tour Packages** – Browse and book guided tours
- 🍽️ **Restaurant Reservations** – Find and book dining experiences
- 📋 **My Bookings** – View, manage, and cancel bookings
- ⭐ **Reviews & Ratings** – Leave feedback for services
- 🆘 **Emergency Support** – SOS button and real-time alerts

### 🎓 For Students
- 💼 **Job Opportunities** – Browse and apply for jobs
- 📄 **CV Upload** – Upload and manage your resume
- 📚 **Learning Resources** – Access courses, tutorials, and e-books
- 🎯 **Internships** – Find and apply for internships
- 🤝 **Networking** – Connect with industry professionals
- 🏅 **Certificates** – Earn certificates upon course completion

### 🗺️ For Tour Guides
- 📝 **Tour Management** – Create, edit, and manage tour packages
- 📅 **Booking Management** – View and confirm tour bookings
- 👤 **Profile Management** – Create and update your guide profile
- 💰 **Earnings Tracking** – Track your earnings and payments
- ⭐ **Reviews & Feedback** – View and respond to client reviews
- ⏰ **Availability Management** – Set your availability schedule

### 👨‍💼 Admin Features
- 👥 **User Management** – Approve, suspend, or delete users
- 📊 **Booking Management** – View and modify all bookings
- 🏷️ **Content Management** – Manage hotels, tours, and restaurants
- 📈 **Reports & Analytics** – View platform statistics
- 🛡️ **Security Monitoring** – Monitor user activity

## 🚀 Installation Guide

### 📋 Prerequisites

Before running SmartTour, make sure you have:

- 🖥️ XAMPP / WAMP / MAMP
- 🐘 PHP 7.4 or higher
- 🗄️ MySQL 5.7 or higher
- 🌐 Web Browser (Chrome / Edge / Firefox)

---

## ⚙️ Installation Steps

### Step 1: Clone the Repository
git clone https://github.com/fathima-azeema/SmartTour.git
cd SmartTour

### Step 2: Setup Server

1. Install and open **XAMPP Control Panel**

2. Start:

```
Apache ✅
MySQL  ✅
```

3. Copy the project folder into:

```
C:\xampp\htdocs\
```

Example:

```
C:\xampp\htdocs\SmartTour
```

---

### Step 3: Setup Database

1. Open phpMyAdmin:

```
http://localhost/phpmyadmin/
```

2. Create a new database:

```sql
CREATE DATABASE tourism_db;
```

3. Import the database file:

```
database.sql
```

4. Select the `tourism_db` database → Import → Choose `database.sql` → Click **Go**

---

### Step 4: Configure Database Connection

Open:

```
config.php
```

Update database credentials:

```php
<?php

define('DB_HOST', 'localhost');
define('DB_USER', 'root');
define('DB_PASS', '');
define('DB_NAME', 'tourism_db');

$conn = new mysqli(
    DB_HOST,
    DB_USER,
    DB_PASS,
    DB_NAME
);

if ($conn->connect_error) {
    die("Database Connection Failed: " . $conn->connect_error);
}

?>
```

---

### Step 5: Run Application

Open your browser:

```
http://localhost/SmartTour/
```

Your SmartTour application is now ready 🚀
